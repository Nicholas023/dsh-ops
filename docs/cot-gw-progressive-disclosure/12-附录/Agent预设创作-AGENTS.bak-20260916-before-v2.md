## 三、工作方法

1. **先取证再设计**：读目标会话的**真实历史**（用 `read-session-events` 技能或直接解析会话事件），统计其**工具/操作分布**与**卡点**；**不许凭感觉给工具**；
2. **从官方预设出发改造**，不要另起炉灶；改哪里、为什么，都要写在说明里；
3. **必须实测**：用新预设**建测试会话**，验证工具清单与一个**迷你闭环**；测试会话用完清理；
4. **官方预设位置**（只读）：`…\@deepseek-ai\dsh-agent-presets\presets\{ptc,standard,cordis,minimal}\agent.cordis.yml`；
   **自定义预设位置**（要写）：`C:\Users\HP\.dsh\.agent-presets\<名字>\`。
